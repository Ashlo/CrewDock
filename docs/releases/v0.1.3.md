# CrewDock v0.1.3

A focused workbench update for browsing, atmosphere, responsiveness, and terminal control.

## Highlights

- Open the built-in browser beside your workspace or place it directly inside a terminal pane
- Use the new Atom Dark theme across CrewDock and its terminal surfaces
- Choose a workspace companion and keep the workspace sidebar calmer and easier to scan
- Keep source-control and telemetry work off the main UI path so CrewDock stays responsive
- Avoid startup stalls when Codex CLI detection is slow or unavailable
- Select terminal text without CrewDock stealing the drag gesture
- Copy terminal selections with Cmd+C on macOS, Ctrl+Shift+C elsewhere, or the context menu
- Keep terminal selections visible when focus moves away from the pane

## Notes

- This release ships as a macOS DMG through GitHub Releases
- Browser content uses CrewDock's native webview support
- Workspace state, terminal layouts, settings, and companion choices remain local
