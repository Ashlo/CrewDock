# CrewDock v0.1.3

CrewDock now supports Windows and adds a task board, safer source control, and more reliable long-running terminal workspaces.

## Highlights

- Install CrewDock on Windows with the native NSIS installer
- Manage work in the new Task Board with To do, In progress, and Done columns, inline editing, drag and drop, and local persistence
- Run source-control actions one at a time with clearer progress, input prompts, and stale-result protection
- Recognize active Codex sessions on macOS and Windows and name their panes from the work being performed
- Restore maximized multi-pane workspaces without losing access to the other panes
- Keep terminals pinned to the bottom after the app has been idle or resized
- Open the built-in browser beside your workspace or inside a terminal pane
- Use the Atom Dark theme and workspace companions across CrewDock's terminal surfaces
- Select and copy terminal text without CrewDock stealing the drag gesture

## Notes

- Windows requires the WebView2 runtime; the installer can download its bootstrapper when needed
- Browser content uses CrewDock's native webview support
- Task Board data, workspace state, terminal layouts, settings, and companion choices remain local
